1HTML kya hai? Document structure aur DOCTYPE

What: HTML (HyperText Markup Language) web page ka structure aur content define karne wali markup language hai. Ye programming language nahi, tags/elements se page ka skeleton banati hai (heading, paragraph, image, link, form).

Basic structure:

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>ShopKart | Online Shopping</title>
  <link rel="stylesheet" href="styles.css">
</head>
<body>
  <h1>Welcome to ShopKart</h1>
  <script src="app.js" defer></script>
</body>
</html>
Part Kaam
<!DOCTYPE html> Browser ko batata hai ye HTML5 hai (standards mode). Na ho to quirks mode (purane buggy rendering rules)
<html lang> Root element; lang screen readers aur SEO ke liye
<head> Metadata: title, meta, CSS links, favicon (page par nahi dikhta)
<body> Jo user ko dikhta hai

Element vs Tag vs Attribute: <a href="/cart">Cart</a> mein <a> opening tag, </a> closing tag, href attribute, poora = element. Void elements (closing tag nahi): <img>, <br>, <input>, <meta>, <link>, <hr>. HTML case-insensitive aur forgiving hai (browser galat markup bhi fix kar deta hai), par validator se check karo.

Use: Third-party embeds (YouTube, maps, payment widgets), isolated content.

Risks aur defenses:

  • Clickjacking: Aapki site ko attacker iframe mein daalke user ko galat click karwaye. Defense: response header X-Frame-Options: DENY ya Content-Security-Policy: frame-ancestors 'self'.
  • Untrusted content ke liye sandbox (scripts, forms, popups restrict; zaroori permissions manually allow).
  • allow attribute se features (camera, geolocation) control.
  • Cross-origin iframe se parent baat karna: postMessage (origin verify karo).

Downsides: SEO mein iframe content parent ka nahi maana jata, performance (extra document), accessibility (title do), responsive banana mushkil (aspect-ratio wrapper). Modern alternative: API integration ya Web Components.

16Browser mein URL type karne par kya hota hai? (classic question)
  1. URL parse: Scheme, host, path. Browser cache/HSTS check.
  2. DNS lookup: shopkart.com → IP (browser cache → OS cache → resolver → root/TLD/authoritative nameservers). CDN/Geo DNS se nearest IP.
  3. TCP connection: 3-way handshake (SYN, SYN-ACK, ACK). (HTTP/3 mein QUIC/UDP.)
  4. TLS handshake (HTTPS): Certificate verify (CA), encryption keys agree.
  5. HTTP request: GET / HTTP/2 + headers (cookies, accept-encoding).
  6. Server/CDN/Load balancer → app → DB; response status + headers (cache-control) + body (gzip/brotli compressed).
  7. Browser parse HTML: DOM banta hai; CSS/JS/images ke liye aur requests (preload scanner parallel mein dhundta hai).
  8. CSSOM, render tree, layout, paint, composite (Q15). JS execute (defer/async rules).
  9. Page interactive: DOMContentLoaded, load events, hydration (React).
  10. Baad ke requests: API calls, lazy assets, service worker cache.

Kahan optimize hota hai: DNS (preconnect/dns-prefetch), TLS (HTTP/2, session resumption), CDN (latency), compression, caching, render path (critical CSS), JS (defer/split). Interview mein is flow ko dobara explain karte waqt har step par ek optimization bolo.

17Web Components, Custom Elements aur Shadow DOM

Web Components: Browser-native reusable components (framework ke bina). 3 technologies: Custom Elements, Shadow DOM, HTML Templates.

<shop-badge count="3"></shop-badge>
<script>
class ShopBadge extends HTMLElement {
  static observedAttributes = ["count"];
  constructor() {
    super();
    this.attachShadow({ mode: "open" });          // Shadow DOM: style/DOM encapsulation
  }
  connectedCallback() { this.render(); }           // DOM mein aaya (mount)
  attributeChangedCallback() { this.render(); }
  render() {
    this.shadowRoot.innerHTML = `
      <style>span { background: crimson; color: #fff; padding: 2px 8px; border-radius: 99px; }</style>
      <span>${this.getAttribute("count") ?? 0}</span>`;
  }
}
customElements.define("shop-badge", ShopBadge);     // naam mein hyphen zaroori
</script>

Shadow DOM: Andar ka CSS bahar leak nahi hota aur bahar ka CSS andar nahi aata (strong encapsulation). Bahar se style: CSS custom properties (--color), ::part(), slots (<slot>). Lifecycle: connectedCallback, disconnectedCallback, attributeChangedCallback, adoptedCallback.

Web Components vs React: WC framework-agnostic aur native, React mein virtual DOM/state/ecosystem. Libraries: Lit. Design systems jo multiple frameworks mein chalane hon unme useful.

19CSS kya hai? Cascade, Inheritance aur CSS add karne ke tareeke

What: CSS (Cascading Style Sheets) HTML ki presentation (color, layout, font, animation) control karti hai. Content (HTML) aur design (CSS) alag.

3 tareeke:

<!-- 1. Inline (avoid: high specificity, reuse nahi) -->
<p style="color: red">Hi</p>
<!-- 2. Internal -->
<style> p { color: red; } </style>
<!-- 3. External (best: cache hota hai, reuse) -->
<link rel="stylesheet" href="styles.css">

(@import slow hota hai, avoid.)

Cascade (kaun si rule jeete): Jab kai rules ek hi element par lagein, order:

  1. Importance (!important, origin: user agent < author < user).
  2. Specificity (selector kitna specific).
  3. Source order (baad wala jeet-ta hai). (Ab @layer bhi cascade ka hissa.)

Inheritance: Kuch properties parent se child ko milti hain (color, font-*, line-height, text-align, visibility, cursor), kuch nahi (margin, padding, border, background, width). Control: inherit, initial, unset, revert.

body { font-family: system-ui, sans-serif; color: #222; }   /* sab children ko inherit */
a { color: inherit; }                                         /* parent ka color */

CSS syntax: selector { property: value; }. Comments /* */. Shorthand: margin: 10px 20px (top/bottom, left/right), border: 1px solid #ccc, font: 16px/1.5 Arial.

25Flexbox: concepts aur properties

What: 1-dimensional layout (row ya column) jahan items space distribute/align hote hain.

.container {
  display: flex;
  flex-direction: row;              /* row | column | row-reverse | column-reverse  (main axis) */
  flex-wrap: wrap;                  /* nowrap (default) | wrap */
  justify-content: space-between;   /* MAIN axis: flex-start | center | space-around | space-evenly */
  align-items: center;              /* CROSS axis: stretch(default) | flex-start | flex-end | baseline */
  align-content: flex-start;        /* multi-line wrapped rows ka cross-axis */
  gap: 16px;
}
.item {
  flex: 1 1 200px;                  /* flex-grow flex-shrink flex-basis */
  align-self: flex-end;             /* is item ka alag cross alignment */
  order: 2;
}

flex: 1 = 1 1 0% (barabar space baanto). flex-grow extra space ka hissa, flex-shrink kam jagah par kitna sikude (0 = nahi), flex-basis starting size (width/height se zyada priority).

Main vs Cross axis: row mein main = horizontal; column mein main = vertical (justify/align ulte ho jate hain).

.nav { display:flex; justify-content:space-between; align-items:center; }
.nav .push-right { margin-left: auto; }          /* ek item ko end par bhej do */
.cards { display:flex; flex-wrap:wrap; gap:16px; }
.cards > * { flex: 1 1 250px; }                  /* responsive bina media query */

Common issues: Item overflow par min-width: 0 (flex item ka default min-width: auto, text overflow karta hai), flex-shrink, align-items: stretch se equal height. margin: auto flex mein absorb karta hai.

64URL Structure, Redirects (301 vs 302), Canonical, 404 aur Pagination

URL best practices: Chhote, readable, lowercase, hyphens, keywords, no session IDs/zyada params, HTTPS, consistent trailing slash, www vs non-www ek hi.

Achha:  https://shopkart.com/men/running-shoes
Bura:   https://shopkart.com/index.php?cat=12&id=9983&sess=ab12

Redirects:

Code Matlab SEO
301 Permanently moved Link equity (ranking) naye URL ko pass
302 / 307 Temporary Original URL index mein rehta hai
308 Permanent, method preserve

Use: Domain/URL change, http→https, www→non-www, purane pages. Redirect chains/loops avoid (301 → 301 → 301 slow + crawl waste). Server-level (Nginx return 301), CDN, framework config ya React Router <Navigate> (client redirect, SEO ke liye weak).

Canonical: Duplicate/near-duplicate URLs (?utm=, filters, /product vs /product/) ke liye preferred URL rel="canonical".

404 vs soft 404: Missing page par asli 404 status (200 + “not found” text = soft 404, index mein kachra). Custom 404 page helpful links ke saath. Permanently removed = 410. SPA mein dikkat: Client router “not found” dikhaye par server 200 de - SSR/server se sahi status do.

Pagination: ?page=2 crawlable <a href> links, self-canonical (page 1 par mat point karo), “Load more” ke saath bhi real links. Infinite scroll ke liye paginated URLs fallback. Faceted filters ko noindex/robots control.

71AWS S3 + CloudFront par React App Deploy (step-by-step)

Architecture: Route 53 -> CloudFront (HTTPS, CDN, cache) -> S3 (private bucket, static files).

aws cloudfront create-invalidation --distribution-id E123ABC --paths "/index.html"

const CACHE = "shopkart-v3";

  e.waitUntil(caches.open(CACHE).then(c => c.addAll(["/", "/offline.html", "/assets/app.js"])));

});

});

  const sentinel = useRef(null);

89Tricky HTML/CSS Output Questions

1. Margin collapse:

<div style="margin-bottom: 20px">A</div>

Gap = 30px (collapse, bada margin), 50 nahi.

2. Specificity:

#a .b { color: red; }  .a.b.c.d.e.f.g.h.i.j.k { color: blue; }

Text red (ID column hamesha bada).

3. em compounding:

Andar wale div ka size 16 x 2 x 2 x 2 = 128px.

4. Width 100% + padding:

.box { width: 100%; padding: 20px; }          /* content-box: overflow! (100% + 40px) */

Fix: box-sizing: border-box.

5. position: absolute bina positioned parent: Page/viewport (initial containing block) ke hisaab se. 6. Float parent height 0 (clearfix). 7. z-index kaam nahi (static element par, ya alag stacking context).

8. inline element par width/height: Asar nahi. 9. visibility:hidden vs display:none (space). 10. 100vh mobile par address bar ki wajah se overflow → dvh.

11. Flex item overflow:

.row { display: flex; } .row > p { white-space: nowrap; }     /* text overflow */

Fix: min-width: 0 + overflow: hidden; text-overflow: ellipsis.

12. Center div (Q28), 13. :nth-child(2n+1) = odd, :first-child vs :first-of-type.

14. <br> vs margin, 15. !important vs inline style: !important rule inline normal style ko hara deti hai.

16. a:hover pehle a:visited ke baad kyun? LVHA order (Link, Visited, Hover, Active) - specificity same hai to baad wala jeet-ta hai.

17. Output?

<p>Hello <span style="display:none">hidden</span> World</p>   <!-- "Hello  World" (extra space collapse -> ek space) -->

HTML mein multiple whitespace ek space ban jata hai (white-space: pre se rokte hain, ya &nbsp;).

18. <button> vs <input type="button">: Button ke andar HTML rakh sakte hain. 19. <script> ka position, <link> ka blocking. 20. id duplicate → getElementById pehla element deta hai (invalid HTML).
